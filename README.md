# CAW (Ethereum Edition)

Intro site for an independently deployed CAW (Gilgamesh design) on Ethereum + Base + Arbitrum, developed by the community.

- Site: https://ql1-infinite42-guppy-histoire.github.io/eth-caw/
- EN / JP, light theme by default with a white/black toggle (`guppy-theme`), like the other Guppy's Guide tool sites.
- Status: **Live on mainnet.** Contracts deployed unmodified from the public GilgameshCaw/Caw code (Sourcify exact match), PathwayExpander ownership renounced, network fees zeroed and locked (one disclosed exception: Babylon's authentication fee of 0.00025 ETH remains, itself locked). The destruction of the deployer key is the operator's declaration — an operational act that cannot be proven on-chain — not a contract-enforced fact. See the site's "Residual powers — full disclosure" section for the exact state, including a labeled comparison of the first (discarded, closed) and current deployments. The Android app is published — current release v0.4.0 (Nov 13, 2026), with name minting reopened on Nov 12, 2026. Reading and posting are open through the first public node, live on the initiator's VPS since Nov 12, 2026.
- This is an independent community deployment — not the official CAW service.
