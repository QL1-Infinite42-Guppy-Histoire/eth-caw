# CAW (Ethereum Edition)

Intro site for an independently deployed CAW (Gilgamesh design) on Ethereum + Base + Arbitrum, developed by the community.

- Site: https://ql1-infinite42-guppy-histoire.github.io/eth-caw/
- EN / JP, light theme by default with a white/black toggle (`guppy-theme`), like the other Guppy's Guide tool sites.
- Status: **Live on mainnet.** Contracts deployed unmodified from the public GilgameshCaw/Caw code (Sourcify exact match), PathwayExpander ownership renounced, network fees zeroed and locked (one disclosed exception: Babylon authentication fee), deployer key destroyed. See the site's "Residual powers — full disclosure" section for the exact state, including a labeled comparison of the first (discarded, closed) and current deployments. The Android app is published (name minting currently under maintenance); reading and posting open when community members run public nodes.
- This is an independent community deployment — not the official CAW service.
